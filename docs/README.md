# Meowtower documentation

For the parent who runs Meowtower on the family Mac. The Parent Room is the part of the game only the parent opens: on the Mac at the local address `./meowtower up` prints, and behind a PIN on the iPad.

## Tasks

- [Export the game data](how-to/export-the-game-data.md): when you want the log and the tables in files, to read or to query.
- [Recompute the derived tables](how-to/recompute-the-derived-tables.md): after a `recompute_failed` notice.

## Reference

- [Parent notices](reference/parent-notices.md): when `./meowtower status` or the Parent Room shows a notice.
