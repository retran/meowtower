# REQ-2208

When the player submits an attempt, the event log MUST record the input summary, the answer as entered and as parsed, the verdict, the game outcome, the trap, the error class, the step matching, the assisted flag, the hint level, the guiding threads spent, and whether and for how long the short solution and the detailed explanation were shown.

The input summary is the time to the first key press, the time of submission, the edits and erasures, the key presses, the focus losses with their duration and the input method.
