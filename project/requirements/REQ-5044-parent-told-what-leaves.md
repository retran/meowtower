# REQ-5044

The Parent Room MUST tell the parent the five kinds of data that leave the Mac: content made without the player, the player's story material (her cleaned free text, invented names, story memory and summary outcome events), the age the parent set, the one-task explanation request and her composed riddles with every number masked.

The parent can only accept what leaves the Mac when the Parent Room names all of it, so the list matches REQ-5042 item for item.
