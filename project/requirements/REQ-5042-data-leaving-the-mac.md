# REQ-5042

The server MUST NOT send off the parent's Mac any data other than content made without the player, the player's story material (her cleaned free text, invented names, story memory and summary outcome events), the age the parent set, the one-task explanation request and a composed riddle with every number masked.

The data concern a child, and every copy off the Mac is out of the parent's control. The event log, answers, times, estimates, node states, scratchpads, lesson tags, reports, the school's goal list and her school group therefore stay on the Mac, apart from the single answer an explanation request carries and the masked riddle.
