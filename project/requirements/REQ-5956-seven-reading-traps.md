# REQ-5956

The Sources track's templates MUST name each reading mistake they detect by one of seven traps: `misread_cell`, `axis_scale`, `legend_misread`, `scale_conversion`, `time_across_hour`, `wrong_source_part` and `ignored_condition`.

Each trap is one misconception, so the misconceptions screen can count it across nodes.
