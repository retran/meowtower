# REQ-7310

While the parent writes a hypothesis or changes its criteria, the form MUST NOT show the current value of any measure the hypothesis links to or names in a condition.

Knowing the outcome shifts a judgement without the judge noticing (Fischhoff, 1975). This buys little, since the parent has usually read the report before, and REQ-7312 is the rule that protects the test.
