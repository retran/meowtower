# REQ-5842

The game MUST NOT show a generated task again, meaning the same template with the same parameters, within 30 days or within the next shows of its subtype numbering 20 % of the subtype's parameter space, whichever ends first, except for basic facts, multiplying and dividing by 10, 100 and 1000 included, and control facts.

A repeated task would drill the answer and inflate the first attempt, while facts need repeats because they measure automaticity.
