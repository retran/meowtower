# REQ-2604

An explanation request MUST hold only the task text as shown, the engine's solution steps and answer, the player's answer, any matched misconception with its engine calculation, the error class and the familiar's kind, name, traits and sample lines.

None of these is personal data, and the request carries no name of the player, no time, no estimate, no node id and no history of other tasks.

Decided by research on the owner's instruction of 2026-09-27.
