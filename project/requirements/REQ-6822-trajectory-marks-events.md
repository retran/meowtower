# REQ-6822

The trajectory MUST mark at its date each short solution or detailed explanation shown on the node, each lesson mark and «тренировали факты» (we practised facts) mark on the node, each review task of the node, and each retention observation of the node with its result.

Each mark is an event that can explain a change in the line, so the parent reads a rise after a lesson or a fall after a gap at the date it happened.
