# REQ-5856

Each maths floor MUST run in this order: an entry scene, an unscored warm-up, either 2 mental arithmetic tasks or one Volley, the Sources track's tasks on a floor that carries them, 1 or 2 rooms of trials, sometimes a Guardian, then the floor chest.

Ten facts at the 3 s threshold take about half a minute of answer time, so the Volley fits the budget of the 2 mental arithmetic tasks it replaces. The Sources track's tasks take no room slot, as RES-4090 sets.
