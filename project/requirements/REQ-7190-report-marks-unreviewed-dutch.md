# REQ-7190

Beside each probe gap, the report MUST show the share of its Dutch observations that came from texts a native speaker reviewed, with the mark «тексты не проверены носителем» (texts not checked by a native speaker) when that share is below one half.

A model's unnatural Dutch biases the gap towards a language cause, and only a native reader closes that bias.
