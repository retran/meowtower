# REQ-5752

The game MUST serve only puzzles whose current content the parent approved.

An edit after approval leaves the puzzle unapproved until the parent approves it again. The owner rules out generating puzzles during play, because an error in a puzzle's statement is especially destructive.

Written from RES-4070 on the owner's instruction of 2026-09-28.
