# REQ-5410

The step count of an unanswerable problem MUST be the step count of the complete problem it withholds a given from.

An unanswerable problem is a T1 to T4 word problem of a subtype `T1.insufficient` to `T4.insufficient`, which can't be answered because a needed given is missing. The step count fixes the tier and the Guardian's ladder, so a missing given must not change it.
