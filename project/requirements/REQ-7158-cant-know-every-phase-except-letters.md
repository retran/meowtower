# REQ-7158

Every T1 to T4 word problem other than a Dutch probe letter MUST offer «Нельзя узнать» (can't be known) beside «Не знаю» (I don't know) in every phase it shows, the model choice, the plan cards and the step fields included.

A button shown only on some problems or in some phases tells the player which problems can be solved before she answers. A probe letter is never unanswerable and carries no phases (REQ-7154, REQ-7156), so leaving the button out of letters hides nothing that exists.
