# REQ-5304

The game MUST ask for an estimate on the unscored tasks of the subtypes that carry one, warm-ups and easy tasks included, at the same rate as on their scored tasks.

An estimate asked only on scored tasks would tell the player which tasks are scored, and the first attempt stays a fair measure only while scored and unscored tasks look alike.
