# REQ-7014

When a linked node has no unassisted first attempt on or before the snapshot's document date, or its last one before that date lies more than 30 days before it, the screen MUST place the goal in no quadrant under «давно не проверялось дома» (not checked at home for a long time).

Thirty days is the game's existing threshold for a node not checked for a long time.
