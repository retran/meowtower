# REQ-5472

On an unanswerable problem, one of the 4 options for what is missing MUST name the given the problem withholds.

An unanswerable problem is a T1 to T4 word problem of a subtype `T1.insufficient` to `T4.insufficient`, which can't be answered because a needed given is missing. Without the withheld given among the options she can't earn the full credit a correct choice brings.
