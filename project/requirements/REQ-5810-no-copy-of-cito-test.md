# REQ-5810

The game MUST NOT show the player a copy of a Cito item, a task laid out as a Cito item or a mock Cito test.

Cito calls practising for its skill tests "geen goed idee" but welcomes practice that builds real skill, so the game builds the skills the M7 and E7 tests measure and never copies the tests. The parent judges.
