# REQ-8100

Withdrawn by ADR-3270 and replaced by REQ-8198: the game now plays as a tabletop RPG, where the world answers at once and decisions can change the plot.

The story pipeline MUST plan an arc, outline an episode, write its beats, critique them and revise them as separate steps.

Hierarchical planning raises coherence in the long-story research.
