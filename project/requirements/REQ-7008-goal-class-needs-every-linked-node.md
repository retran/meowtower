# REQ-7008

A goal MUST count as high at home when every linked node is high, as low at home when every linked node is low, and as neither otherwise.

"Every linked node" is the rule the "home and school" screen already uses for its marks, and a goal half high and half low at home has no single home reading, so it lands in no quadrant.
