# REQ-5336

The game MUST offer the inverse check only on a bare expression whose final operation is addition, subtraction, multiplication or division, and never on a word problem, one-step ones included.

On a word problem the check's prompt names the operation, which is the modelling step the task measures, so it would be a hint. Decided on 2026-09-28 in the research.
