# REQ-5368

The estimate matrix MUST show «мало данных» (too little data) in each cell that holds fewer than 5 answers.

One estimate is right by chance one time in four, so a cell of a few answers says little. The number 5 is a default chosen in writing this requirement, because the research names no number; the design step can change it through a new requirement.
