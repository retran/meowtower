# REQ-6330

Every model call the sandbox makes MUST pass the same checks on what leaves the Mac, at the same privacy level, as a call by the same role in play.

A sandbox built from a snapshot carries her story material and her own text, and the checks can't tell which start a sandbox came from, so a sandbox begun from an empty profile passes them too.
