# REQ-1958

When the story reaches a planned friendship, a check MUST decide it: a clean or partial outcome makes the friendship, and a failed one or «Не знаю» (I don't know) moves it to a later scene of the same arc.

A friendship the story plans is still earned, and a failed one waits instead of vanishing, so the arc still reaches it.
