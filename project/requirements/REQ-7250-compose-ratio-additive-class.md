# REQ-7250

When the target is the part K : a · b from a known part K, with a and b as REQ-7222 names them, the engine MUST give the error class `compose_ratio_additive` to a confirmed graph whose structure is K + b − a, whatever its value.

Misailidou and Williams (2003) name the additive strategy the most reported error in ratio tasks. A share of a total gets no additive class, because no study RES-4260 read describes an additive pattern for it. The class sits beside the verdict the value comparison gives.
