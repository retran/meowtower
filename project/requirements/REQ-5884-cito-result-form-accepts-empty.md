# REQ-5884

The Cito result form MUST save a result with any field left empty except the test moment and the subject.

The school decides whether parents see the expected advice, and the bare-versus-context split sits on the teacher's side. Requiring the moment and the subject is a default chosen while writing this requirement, because a result without them can't be placed on the timeline.
