# REQ-1956

A familiar's friendship MUST grow by 3 points for a clean check it shared with the player, by 1 for a partial one, by 0 for a failed one or «Не знаю» (I don't know), and by 1 for each scene, rest stop or camp talk it shares.

Solving well with a pet is what grows it, so the player has a reason to solve, and the small amount for shared play keeps a pet from standing still on a hard day. The amounts are starting values that I chose for the content file.
