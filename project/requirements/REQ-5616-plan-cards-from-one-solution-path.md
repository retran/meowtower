# REQ-5616

The needed cards of a plan MUST come from exactly one valid solution path of the problem, one card per step, with the problem's question as the last card.

Cards drawn from two valid paths, such as 3 · 5 + 3 · 7 and 3 · (5 + 7), would make two different card sets right.
