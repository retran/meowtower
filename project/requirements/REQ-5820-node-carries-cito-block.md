# REQ-5820

Each node and subtype of the skill graph MUST carry a Cito block from 1 to 6 or no block, with no block on every S node and every stretch node.

The six blocks follow the owner's list of the tested skills in priority order: basic operations, the times tables and division, fractions with decimals, percentages and ratios, measures, geometry, and word problems. S nodes hold topics of the Russian programme only and stretch nodes lie beyond group 8, so neither is on the M7 or E7 test.
