# REQ-8210

Withdrawn by ADR-3270 and replaced by REQ-8242: the plain template stays the fallback.

When a live story can't be written, the game MUST set the task with text prepared beforehand in the scenario or the language's content file.

This covers a failed judge, a timeout, a pause, a spent budget and an unset model.
