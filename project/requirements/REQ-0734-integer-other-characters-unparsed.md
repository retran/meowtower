# REQ-0734

When an integer entry holds any character other than digits, spaces and a leading minus, the engine MUST return the entry to the player as unparsed input to correct.

The leading minus is allowed because the number tasks N7 and N8 have negative answers. Default chosen by the requirements step. The research names no allowed character but digits and spaces.
