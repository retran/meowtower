# REQ-5976

Text inside a source MUST have a font size of at least 24 CSS pixels, the `task` style, in the normal text size, and at least 28 CSS pixels with large text.

The task text is the main text of the task window where a source is read, and pinch zoom carries the maps that fit fewer labels.
