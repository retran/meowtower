# REQ-5838

Every change to the fact threshold, the parent's included, MUST create a new threshold version that the event log records.

The fluency threshold is an external standard that only a person changes, each change as a new version, and a free parent control would break that. Decided by research on the owner's instruction of 2026-09-28.
