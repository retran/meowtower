# REQ-6934

The game MUST compute from the event log a `firstExposure` for the first show of each subtype, of each subtype in each format and of each subtype in each context, at most once for each.

Near and far transfer are defined on these three kinds of first meeting, and the report counts each first meeting once; REQ-6944 settles a show that is new on several counts.
