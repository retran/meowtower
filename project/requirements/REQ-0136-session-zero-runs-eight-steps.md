# REQ-0136

Session 0 MUST run these eight steps in order: the transparency talk; creating the heroine; choosing the starting familiar; the first chest; training on trivial numbers; motor calibration of 10 plain-input tasks; the vocabulary probe; and the campaign's first scene with the end of the row.
