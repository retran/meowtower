# REQ-7688

The Parent Room MUST draw its screens with a widget library for admin interfaces that the game's server serves, show a choice among a few values as a segmented control and a setting as a row of its name and its control, and show its menu as a bar above the screen when the window is under 768 px wide.

The owner asked for an attractive widget library apart from the game's look, the server keeps the room working on the home network alone, a segmented control shows every value at once, and a narrow window has no width for a panel beside the screen.
