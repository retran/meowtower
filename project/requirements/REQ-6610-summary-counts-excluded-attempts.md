# REQ-6610

After the MVP, the full report's summary MUST show how many attempts the parent excluded, with how many of them were right and how many wrong.

Exclusion is the one path by which an approved rule removes evidence, and the split makes a one-sided exclusion visible without taking away the parent's right to exclude an ambiguous task. Default chosen by the requirements step: RES-4200 keeps report v1 as approved for the MVP, so this applies from the full report.
