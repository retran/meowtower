# REQ-6626

Every interpretation the report draws on its own MUST read as «что проверить» (what to check) and name a check the game or the parent can run: a probe, a retention check, the sandbox or a question to the teacher.

A line worded as a check to run stays a question the next data can answer, where a verdict would close it.
