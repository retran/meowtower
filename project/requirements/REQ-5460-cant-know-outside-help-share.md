# REQ-5460

An answer of «Нельзя узнать» (can't be known) MUST NOT count as «Не знаю» (I don't know) in the help limit or in the help share that flags an adventure and raises review.

The help limit and the help share count how much she leans on help, and «Нельзя узнать» is a claim about the problem, not a request for help.
