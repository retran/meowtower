# REQ-5256

Until a record defines when the player solves a problem type at least at "understands", the Director MUST offer a riddle of a type only when the node of that type's tier is at least at "understands".

ADR-0060 keeps states per node, not per problem type. Default chosen by the requirements step: the tier's node stands in for the type.
