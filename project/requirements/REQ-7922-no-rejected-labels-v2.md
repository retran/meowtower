# REQ-7922

An interface label MUST NOT read «Решение» (the solution), «Твой ответ» (your answer), «Проверить» (Check), «Подсказка» (Hint), «Сдаться» (Give up), «Выйти» (Exit), «Пауза» (Pause), «Осталось N минут» (N minutes left), «Серия» (Streak) or «Дней подряд» (Days in a row).

These labels bring back the test, the clock or the streak the game leaves out; «Правильный ответ» and «Верно» are allowed now, because the task window marks a result plainly.
