# REQ-7342

The report MUST show beside each hypothesis how many times its label has changed because of new play, leaving out each change a version caused and each reset to «мало данных» that a change of criteria caused.

A label that has changed often is weak evidence, and the parent can see that only from the count. A reset after new criteria is the parent's act, and REQ-7318 already marks it with its date.
