# REQ-5124

A familiar's framing line MUST carry no number, step, operation or reference to the parts of a task.

A framing line is written for a familiar and a rung, never for a template, and shows before the attempt that measures her, so a line that names "the first question" is wrong for a template whose first step is something else. The parent judges each line.
