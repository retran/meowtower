# REQ-8444

Before an adventure plays, code MUST refuse a scenario whose find or creature is not in the content, whose creature doesn't live in the place's element, whose lock has no other way on, or which holds more catch scenes than the content allows.

A model can invent an item or a creature, and the check keeps the story inside the content.
