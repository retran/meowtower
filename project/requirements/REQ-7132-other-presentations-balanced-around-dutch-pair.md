# REQ-7132

The game MUST assign the positions of the bare, Russian and source presentations across the probe families built so far, repeatably from the adventure's seed, so that each comes before the Dutch pair as often as after it, give or take one family, with none placed between the Dutch presentation and the Dutch-after-words presentation.

Each meeting with a construction teaches something, so a fixed order would credit that practice to one presentation. A presentation between the pair would add practice to the after-words presentation alone, so I chose to forbid that position as a default the research left open. The seed makes a replay give the same order. The Dutch pair keeps its own order (REQ-7130).
