# REQ-6054

School goals the parent enters in the Parent Room MUST map to nodes the same way as goals from a snapshot, through the catalogue mapping or the parent's own mapping, with no model involved.

One mapping path keeps entered goals and imported goals comparable, and goal wording may not go to a model outside the home (REQ-6048).
