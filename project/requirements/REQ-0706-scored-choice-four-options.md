# REQ-0706

Every scored choice task MUST offer at least 4 options.

A yes/no question lets the player guess 1 in 2, so a scored yes/no question is asked as a choice from four, for example «у какой из четырёх фигур есть ось симметрии» (which of the four shapes has an axis of symmetry).
