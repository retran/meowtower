# REQ-6810

The weekly breakdown and the trajectory MUST count only graded first attempts shown for a block, a probe, review, a lesson recheck or a retention check that the knowledge model doesn't drop, and so leave out rapid guesses, excluded tasks, second attempts, mental arithmetic, control facts, Volley rows and tasks showing a new form.

Mental arithmetic, control facts and the Volley measure a fact's speed against a time threshold, and a new form writes its own stream, so neither says how much help a node needed.
