# REQ-5278

The reference set of acceptance test 3 MUST hold 200 texts, among them child-like spelling errors, dictated text, number words, problems with no question, irrelevant data, every verdict, every compose error class and correct problems in each allowed order of operands.

At 190 of 200 the 95% interval reaches down to about 91%, the bound REQ-5280 reports against, and a smaller set would widen it. Solvers were shown to pass benchmarks on shallow cues that the listed variations defeat (Patel, Bhattamishra and Goyal, 2021).
