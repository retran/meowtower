# REQ-7350

A hypothesis's text, criteria, links, condition states and label MUST NOT leave the Mac.

A hypothesis can hold the player's name or school, and none of the kinds of data the approved rules let leave the Mac covers it. A check over the code verifies that no request class of the model gateway carries a field for them, because a test catches only the paths it runs. The gateway is the only route off the Mac apart from the export for the school, and REQ-6070 keeps home data out of that export. Default chosen by the requirements step: no separate requirement keeps hypotheses out of the export for the school, because REQ-6070 already keeps all home data and free text out of it.
