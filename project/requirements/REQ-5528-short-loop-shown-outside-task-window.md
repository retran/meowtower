# REQ-5528

When the player earns the short loop, the game MUST play the special spell animation and show the System line «Обнаружен короткий путь. Длинный путь обиделся» (A short path was found. The long path took offence) outside the task window.

The task window holds no effect, so the animation waits until the window closes.
