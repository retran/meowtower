# REQ-3660

Natural science questions MUST come only from the science bank, never from text generated during play.

A blind solve checks arithmetic, not facts, so it can't catch a factual error in a question generated live. An agent may draft the bank's questions; each still reaches the player only after the parent approves it.

Imposed by the owner's decision of 2026-09-27.
