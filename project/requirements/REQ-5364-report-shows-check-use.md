# REQ-5364

The report MUST show the share of the tasks offering the inverse check on which the player used it, per week, beside the numbers of saved and spoiled answers.

Read beside the saves and spoils, the share tells the parent whether the player has the checking habit and whether the habit helps her. The weekly period is a default chosen in writing this requirement.
