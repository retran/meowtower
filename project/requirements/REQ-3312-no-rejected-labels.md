# REQ-3312

An interface label MUST NOT read «Правильный ответ» (the correct answer), «Решение» (the solution), «Твой ответ» (your answer), «Проверить» (Check), «Подсказка» (Hint), «Сдаться» (Give up), «Верно» (correct), «Выйти» (Exit), «Пауза» (Pause), «Осталось N минут» (N minutes left), «Серия» (Streak) or «Дней подряд» (Days in a row).

Each of these labels brings back the test, the clock or the streak the game leaves out.
