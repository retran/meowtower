# REQ-7024

The school side of a Cito row MUST count a category the teacher's analysis marks «Opvallend» or «Zeer opvallend» (notable or very notable) below expectation as a relative weakness, one marked so above expectation as a relative strength, and one marked «Niet opvallend» (not notable) as neither, placing that row in no quadrant.

Cito compares each category with the expected score of pupils of the same overall ability, so the category has no level of its own to cut, only a strength or weakness within the player's profile.
