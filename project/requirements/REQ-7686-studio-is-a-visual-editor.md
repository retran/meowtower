# REQ-7686

The studio MUST show the selected node's fields and actions in an inspector beside the graph on a screen at least 1100 px wide, under a toolbar with the breadcrumb, with the sandbox's levers and forced outcome kept on the testing screen beside the checklist.

The graph then stays in view while a node is edited, and the tools that set the sandbox's state sit beside what is left to test.
