# REQ-0424

Withdrawn by ADR-3220 and replaced by REQ-8024: the game accumulates no experience.

When the player answers a second attempt correctly, the game MUST give base experience and no bonus.

Otherwise pressing «Не знаю» (I don't know) to reach the walkthrough would pay.
