# REQ-7108

Every probe family MUST hold exactly these presentations: on a maths template, a bare, a Russian, a Dutch and a Dutch-after-words presentation, plus a Dutch source presentation when the template draws a table or chart; on a Sources track template, a Russian source, a Dutch source and a Dutch source after the words.

A task whose content is a source has no bare form, and the Sources track's own tasks already give a Russian source stream to compare with. The source presentation of a maths family is Dutch because the addendum lists it among the Dutch presentations. As a default, a Sources family's three presentations fill the report's Russian, Dutch and Dutch-after-words cells, and the source cell holds only the source presentations of maths families.
