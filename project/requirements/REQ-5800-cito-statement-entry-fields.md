# REQ-5800

Each statement about Cito that the game's logic or report text depends on MUST be stored as its own entry holding the statement and, unless the entry is marked "unconfirmed", the URL of the Cito page it rests on, a verbatim quotation from that page and the date the quotation was checked.

Cito rewrites its pages, and only a statement tied to a quotation on a named page can be checked again.
