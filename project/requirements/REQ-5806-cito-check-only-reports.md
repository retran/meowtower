# REQ-5806

The Cito check, whether the parent starts it in the Parent Room or a person starts it from the command line, MUST do no more than re-read each Cito page, report the pages that changed and the quotations that no longer appear, and set the "unconfirmed" mark on the entries they affect.

A person judges whether a changed page changes a rule, because no approved model role reads Cito's pages and a check that rewrote rules would change the game's logic with nobody reviewing it. Decided by research on the owner's instruction of 2026-09-28.
