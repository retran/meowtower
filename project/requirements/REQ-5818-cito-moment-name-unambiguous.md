# REQ-5818

Every record and screen that names a Cito test moment MUST use a name that can't be read as a graph node or a science topic, such as `cito:M7`.

M7 is also the graph node for the volume of a cuboid and E1 to E5 name science topics, so a report line "M7: 80 % ready" would read as the volume node.
