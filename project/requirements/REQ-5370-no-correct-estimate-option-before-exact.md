# REQ-5370

The server MUST NOT send the client which estimate option is correct, or any value the verdict on the estimate could be worked out from, before the player submits the exact answer of the same task.

A client that holds the correct option can show or leak the estimate's verdict early, which would tell her the size of the result before she calculates it.
