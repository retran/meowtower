# REQ-6080

A withdrawn snapshot's file and values MUST NOT leave the parent's Mac by any route.

Withdrawal hides a snapshot from every view but leaves its file and events in place, and it is most often a wrong pupil's record, so withdrawal never makes it safe to send anywhere, the export for the school included.
