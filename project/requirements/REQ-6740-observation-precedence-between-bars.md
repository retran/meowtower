# REQ-6740

When an observation meets the sources of more than one bar, it MUST feed only the first of these that applies: basic facts for an attempt carrying a `factId`, then retention, transfer and finding patterns, then the bar the stream-to-dimension content assigns, except that the bare side of the language and format bar also reads what computational accuracy reads, as REQ-6736 allows.

REQ-6736 lets one observation feed one dimension, and without an order an attempt on node S6, or a retention check on a bare task of a mastered node, would meet two bars' sources. Default chosen by the requirements step: the narrow bars take precedence, because they have the fewest observations and computational accuracy has hundreds.
