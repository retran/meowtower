# REQ-5412

Every T1 to T4 word problem MUST have 4 options for what is missing, each naming a quantity of the problem's story that its text doesn't state.

One rule for both kinds keeps the options from telling them apart: if only unanswerable problems had options, or if a solvable problem's options named givens printed in its text, a client comparing the options would know the kind.
