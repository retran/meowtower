# REQ-2378

When a day's active time passes 120 minutes, the summary screen MUST mark that day «долгий день» (a long day).

The mark only informs the parent and changes nothing in play; the 120 minutes follow the 2-hour limit on recreational screen time in the Canadian 24-Hour Movement Guidelines.

Decided by research on the owner's instruction of 2026-09-27.
