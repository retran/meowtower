# REQ-5974

On the tablet, every tappable part of a source MUST have a touch zone of at least 56 CSS pixels in both directions.

56 px is the approved tablet minimum (RES-3100), and it also meets the addendum's 44 by 44 pt, because on iPad Safari one CSS pixel is one point.
