# REQ-5552

A grouping-task attempt MUST NOT count towards an adventure's minimum of graded first attempts.

The minimum exists to feed the model, and REQ-5538 keeps grouping attempts out of it. I chose to state this beside REQ-1040 and leave that requirement standing, because this rule only narrows what counts, and REQ-5550 keeps the adventure's count at the minimum.
