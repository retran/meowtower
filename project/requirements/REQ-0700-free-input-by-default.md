# REQ-0700

Every task MUST take its answer as free input, except tasks on recognising shapes, nets, symmetry, «объясни, почему» (explain why), natural science and problem models, which take a choice of options.

A typed answer can't be guessed, so a choice of options appears only where typing the answer is awkward.
