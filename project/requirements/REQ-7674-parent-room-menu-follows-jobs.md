# REQ-7674

The Parent Room's menu MUST name the parent's jobs in this order: «Обзор» (overview), «Сюжет» (story), «Проверка» (testing), the lab's «Шаблоны» (templates), «Промпты» (prompts) and «Экраны» (screens), «Журналы» (logs), «Устройства» (devices), «Настройки» (settings) and «Аккаунт» (account), with «Выйти в игру» (back to the game) at its foot.

The parent comes for a job and not for a module of the code, so the menu names the jobs RES-4322 found, in the order a visit follows: see how it went, prepare, test, check, read, run the household.
