# REQ-5604

When a Guardian sets a word problem, the problem MUST open with a model choice, a plan or neither, and take step-by-step or final-answer input, by the shares REQ-5606, REQ-5610, REQ-5670 and REQ-0703 set.

Word problems reach play only through the Guardians, so a rule that opens every Guardian problem with a model choice and step input leaves no problem for a plan and breaks the step-input band of REQ-0703. A problem with missing data takes its phases by the same shares, because RES-4040 has it show the phases a solvable problem would, so a phase that differs doesn't give it away.
