# REQ-5666

The report MUST show word problem results as two crosses sharing the answer axis: model choice by answer on problems that opened with a model choice, and plan by answer on problems that opened with a plan.

No problem has both a model choice and a plan, so the addendum's matrix of model by plan by answer can't be a cross of one problem.
