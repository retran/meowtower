# REQ-5462

Beside the word-problem matrix, the report MUST show as separate counts «Не знаю» (I don't know), «Нельзя узнать» (can't be known) on solvable problems, answers of class `used_extra_data` and numbers given for unanswerable problems.

None of these four is a modelling error or a calculation error, so the matrix, which splits only those two, can't hold them.
