# REQ-6704

The profile MUST show exactly eight bars, in this fixed order: basic facts, computational accuracy, conceptual understanding, model building, transfer, finding patterns, retention, and language and format.

A fixed order lets the parent find each bar in the same place every time, and keeps the bars from being read as a ranking.
