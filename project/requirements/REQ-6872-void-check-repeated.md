# REQ-6872

When a retention check gives no observation, such as for a rapid guess, an excluded task or a walkthrough on a direct prerequisite, but not for a lesson mark, which cancels the plan, the Director MUST plan the same check number again 28 to 35 game days after that attempt and hold the node from that plan's logging.

A void attempt says nothing about retention, and it was still a meeting with the node, so the gap starts again.
