# REQ-6608

When the report is exported as a PDF snapshot, the snapshot MUST hold every screen of the report, with the node card of every node.

A snapshot that picks its screens is a curated report in another form. Default chosen by the requirements step: every node's card counts as a screen, because a snapshot with some cards picks which nodes the reader sees.
