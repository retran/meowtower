# REQ-6220

Once the free pen has opened, and unless the parent has switched it off, the game MUST let the player open the free pen at any moment the task window isn't open, during an adventure included.

The task window holds only the task and its controls, so the free pen stays outside it, and outside it the free pen is always there for her to write when she wants to.
