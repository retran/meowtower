# REQ-2648

The Parent Room MUST tell the parent, for each check on the player's text, where it runs and, for each place off the Mac, which company reads the text, in which country and whether it keeps any of it, the fallback included, as the gateway is configured when the parent opens the page.

A judge on the Mac sends her text to no company, but a check that stays hosted or falls back still does, and the answer changes as checks move after the bake-off. The page is checked against the configuration the gateway runs: where each check goes comes from it, and the company, country and retention of each place from the provider list the gateway checks at start-up (ADR-0100). The Master's reading of her story material is told under REQ-2636.
