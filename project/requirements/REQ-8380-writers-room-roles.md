# REQ-8380

The story pipeline MUST run as a writers' room: an arc lead, a story editor who breaks beats, a staff writer who drafts, a script doctor who rewrites and a keeper who tracks continuity, with the parent as showrunner who approves.

Each agent has one job, and the keeper updates the library and the bible.
