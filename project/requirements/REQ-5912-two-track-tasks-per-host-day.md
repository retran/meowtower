# REQ-5912

When the Director plans an adventure day that holds at least one host floor, it MUST plan 2 Sources track tasks on the first host floor of that plan.

The addendum asks for about 2 a day. I chose as the default exactly 2 a day, both on the first host floor the day plans, because "about" gives a test nothing to check and the first host floor is the one the player is likeliest to reach.
