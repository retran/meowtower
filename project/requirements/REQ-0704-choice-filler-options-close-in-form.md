# REQ-0704

When a choice task's traps give fewer wrong answers than the task needs, each remaining option MUST be close in form to the correct answer: the same answer kind, and the same number of digits or the same denominator.

An option that looks different from the rest can be ruled out without doing the maths. Default chosen by the requirements step. The research doesn't say what close in form means.
