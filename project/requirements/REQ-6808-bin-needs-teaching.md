# REQ-6808

The weekly breakdown MUST put every first attempt that ends `partial` or `alt`, «Не знаю» (I don't know) included, in «требует обучения» (needs teaching), whatever hints came before it.

The game shows the short solution after exactly these outcomes, and that is the walkthrough («разбор») in the owner's name for the bin, «требует обучения (разбор)». So every first attempt lands in exactly one bin.
