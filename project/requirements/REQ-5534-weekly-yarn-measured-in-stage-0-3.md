# REQ-5534

During stage 0.3, the game MUST give the owner, for each week, the star yarn the player earned per source, taken from the event log, with the short loop as a source of its own.

The short loop adds up to 21 yarn a week at 3 floors a day and 28 at 4, which is a ceiling and not a forecast, so only the measured weeks show whether the forge recipes need resizing. The owner accepts the measure when every week of stage 0.3 has a figure per source.
