# REQ-8002

Withdrawn by ADR-3220 and replaced by REQ-8010, REQ-8012 and REQ-8014: the owner said the game is an RPG, so the player sees her ability levels and rank.

The game MUST show the player a stage or rank by name and never the estimate as a number.

This keeps a child's view coarse and the numbers with the parent.
