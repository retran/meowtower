# REQ-6050

The game MUST propose the nodes for a school goal only from a mapping of the vendor's public goal catalogue kept on the Mac.

Built from the public catalogue alone, the mapping is content made without the player, and one mapping serves every snapshot. REQ-6092 covers the case where no public catalogue exists.
