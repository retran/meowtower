# REQ-8430

A parent MUST be able to attach pictures to a character, a place, an item or a fact in the studio's libraries, and an encounter MUST be able to use a library picture in place of its own.

The owner asked for this on 2026-11-01. Without it the parent would draw the same person again for every encounter.
