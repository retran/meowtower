# REQ-6832

An attempt MUST NOT count as a retention observation when, since the node's latest meeting before that attempt's task was shown, a short solution, a detailed explanation or a hint rung was shown on a direct prerequisite of the node under the graph version active at the attempt.

No program can judge per task which walkthrough hints at the answer, so every walkthrough on a direct prerequisite spoils it. Practice inside a larger task that uses the node doesn't, because that is how a skill lasts at school too.
