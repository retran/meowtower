# REQ-2600

The server MUST NOT send off the parent's Mac any data other than content made without the player, the player's story material (her cleaned free text, invented names, story memory and summary outcome events) and the one-task explanation request.

The event log, answers, times, estimates, node states, scratchpads, lesson tags and reports therefore stay on the Mac, apart from the single answer an explanation request carries.
