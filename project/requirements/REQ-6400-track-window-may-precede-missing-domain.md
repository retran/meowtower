# REQ-6400

When a maths domain has had no floor for 2 adventure days in a row, the route MUST take that domain before any other floor except a host floor that the Sources track's window (REQ-5914) brings to the first place.

Both windows can fall due on the same day while no due domain can carry track tasks, and only one floor comes first. A domain that misses its place comes first on the next route, while a missed track window loses the only reading evidence the game collects.

Imposed by the owner's instruction of 2026-09-28 to decide the conflicts the specification step found.
