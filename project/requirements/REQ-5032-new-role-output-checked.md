# REQ-5032

The game MUST use the output of every model role the owner's addendum 1 adds only after that output has passed a check against the role's declared output format and the data rules that bind the role, and otherwise use the role's fallback.

A model can return anything, and an unchecked output could put a wrong verdict into the knowledge model, give maths content to the Master or show the player text nobody approved.
