# REQ-5814

The Parent Room MUST let the parent set a date for each Cito horizon, with 2027-01-15 for M7 and 2027-05-15 for E7 until the parent changes it.

The school picks its own test days, and Cito advises mid-January to mid-February and mid-May to mid-June. The defaults sit at or just before the start of each period, because a horizon a few weeks early costs a little priority while one a few weeks late misses the test.
