# REQ-5470

The button that claims a word problem can't be answered MUST carry the label «Нельзя узнать» (can't be known), different from the label «Не знаю» (I don't know).

«Не знаю» says she can't solve the problem and «Нельзя узнать» says the problem can't be solved, so two labels that read alike would mix the two answers the log keeps apart.
