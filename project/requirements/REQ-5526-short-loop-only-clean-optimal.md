# REQ-5526

The short loop reward, «Короткая петля» (The short loop), MUST give 1 star yarn to a `clean` unassisted first attempt with an `optimal` grouping, and to no other attempt.

ADR-0140 keeps accuracy bonuses for the unassisted first attempt, and a spell has only the three outcomes of RES-1700 conclusion 13, so the short loop can only decorate a `clean` one.
