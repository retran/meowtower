# REQ-6954

For a warm-up, a second attempt, a retention check, a Dutch probe presentation, a task carrying a new form or a task on a live frame, the game MUST choose a subtype, and a subtype's format, that it has already shown the player whenever one fits the slot.

A first encounter shown in one of these slots is used up with no clean observation, or mixes transfer into another measurement. When nothing shown fits, as in the first warm-up of her first adventure, the slot takes a new one, which REQ-6946 makes ineligible and marks as used; this default was chosen by the requirements step.
