# REQ-7154

A Dutch probe letter on a T1 to T4 template MUST take the final answer only, in every presentation, with no model choice, plan cards, step input, «Нельзя узнать» (can't be known) or options for what is missing.

The bare presentation can carry none of these, so the text presentations must not either, or the presentations would differ in more than language. Options in Russian would also translate the question inside a Dutch presentation.
