# REQ-6910

Every template of the context format MUST list the contexts its structure admits.

The frame requests of REQ-6908 and the warning of REQ-6912 work from this list, and a template with one context can never give the hold of REQ-6926 a context to keep back; REQ-6926 itself counts the contexts that have an accepted frame. The static check covers that the list is present and drawn from the closed list of contexts.
