# REQ-7160

Every T1 to T4 word problem other than a Dutch probe letter MUST have 4 options for what is missing, each naming a quantity of the problem's story that its text doesn't state.

One rule for both kinds keeps the options from telling a solvable problem from an unanswerable one. A probe letter is never unanswerable, so it needs no options, and Russian options in a Dutch letter would translate its question.
