# REQ-1950

Withdrawn by ADR-3450 and replaced by REQ-1972, REQ-1974 and REQ-1976: the owner decided on 2026-11-15 that every check, a battle's included, is a maths task.

If familiar battles are built, the outcome of a battle MUST depend only on the player's tactical choices, so the same choices against the same opponent always give the same result.

A result that drifted with a model's reply would feel unfair and couldn't be explained.
