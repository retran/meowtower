# REQ-6922

A task built on a table, chart, timetable or map MUST belong to a node of the Sources track, never to a format of a maths subtype.

The Sources track already keeps tables, charts, timetables and maps in five nodes of their own, apart from the maths nodes, so a source task is a task of a track subtype. A maths word problem that only quotes a number from a small table stays a task of its maths node.
