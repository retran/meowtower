# REQ-6748

The computational accuracy bar MUST read only unassisted first attempts without a `factId` on bare tasks of nodes that were «бегло» (fluent) or «устойчиво» (stable) at the moment of the attempt.

Tasks on mastered nodes are review, not frontier tasks the Director set near her limit, so this bar escapes most of the Director's pull towards 70 to 80 %. A node that changes state inside the window counts only for the attempts made while it was fluent or stable.
