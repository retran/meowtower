# REQ-7248

The engine MUST give the error class `compose_percent_as_number` to a confirmed graph that uses a percentage's token as a plain operand where the target's expansion holds it inside a percentage, as in 80 − 20 for `80 − 20 % от 80`.

Jacobs Danan and Gelman (2018) found that about a third of the adults they asked applied whole-number arithmetic to percentages. The class sits beside the verdict the value comparison gives.
