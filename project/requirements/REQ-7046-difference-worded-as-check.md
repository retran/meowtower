# REQ-7046

Where the school's value and the home state for a goal or a Cito category differ, the "home and school" report MUST word the difference as a difference between two measures that names a possible cause only as something to check, and never as a fault in the player or in either measure.

The parent judges the wording. A cause named as a check can be tested and dropped; a cause named as a finding can't. Which causes each quadrant names, on both sides, is REQ-7042.
