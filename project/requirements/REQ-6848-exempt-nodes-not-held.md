# REQ-6848

The Director MUST NOT hold or plan a retention check for a node that supplies control facts, a basic-fact node or the nodes T1 to T4.

Control facts come at fixed points of every adventure, the Guardian's step ladder needs the T nodes, and the basic facts measure automaticity by frequent showing, so a hold would break an approved rule.
