# REQ-5992

Every Sources track task MUST ask at one of four question levels: find, compare or select, calculate from the source, or combine.

Cito also tests choosing a suitable source and reading a schema or flow chart; the track leaves both out, because they would change more approved records for a skill Cito's current tests don't report.
