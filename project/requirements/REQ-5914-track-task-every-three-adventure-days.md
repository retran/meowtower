# REQ-5914

The Director MUST plan host floors so that in any 3 consecutive adventure days the player completes at least one floor carrying a Sources track task.

Track tasks live only on S, M, G and P floors (REQ-5918), and the domain window brings one of those within 3 days only while each day completes 3 floors, so after short days the Director brings a host floor forward and never lets the window lapse. Only a completed floor counts, because an abandoned floor may never have shown the player its source.
