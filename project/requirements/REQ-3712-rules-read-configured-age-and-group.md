# REQ-3712

Every rule that depends on the player's real name, age or school group MUST read the values the parent set, never a value fixed in the code, the content or a tracked file.

This covers the knowledge model's starting values, the readability limits for her age and the Master's writing level. The values stay in the local database, which the repository never holds.
