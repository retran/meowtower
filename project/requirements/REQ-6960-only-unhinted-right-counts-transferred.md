# REQ-6960

An eligible first encounter MUST count as transferred only when it is «сама», a right answer with no hint before it, and as not transferred in every other case.

This widens the addendum's "without help": a hinted first attempt stays an observation of failed transfer, because the player opens the hint ladder exactly when she can't transfer, and dropping those attempts would push the share up. A hint before the answer also removes the recognition part of the test.
