# REQ-7254

The composing stream MUST keep, for each construction and each form, text or cards, the count of each riddle verdict other than `unparsed`.

A construction riddle has no tier and no problem type, so REQ-5252's counts have no key for it. An `unparsed` riddle is the parser's failure, not hers.
