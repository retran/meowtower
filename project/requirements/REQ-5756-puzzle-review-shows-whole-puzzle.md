# REQ-5756

For each puzzle, the review screen MUST show the statement, the three hint rungs, the full solution, the check's result on the reference solution and the source of the idea.

The addendum budgets about 1.8 minutes of the parent's review for each puzzle, and a queue that long tends to end approved unread unless everything to judge is on one screen.
