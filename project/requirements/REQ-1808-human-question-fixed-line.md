# REQ-1808

When the player asks directly whether the narrator is a human or an AI, the Master MUST answer with the fixed System line «Рассказчик этой истории — компьютерная программа. Человеком не является. Историю мы пишем вместе.» (The narrator of this story is a computer program. It is not a human. We write the story together.).
