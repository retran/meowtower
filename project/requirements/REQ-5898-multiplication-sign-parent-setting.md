# REQ-5898

Task text rendered in Russian MUST write multiplication with the sign the parent set, «×» by default or «·», and division with «:».

Whether the player's school writes «×» is unconfirmed at Cito's pages and only the parent can check it. This one setting overrides the locale's notation, and the decimal comma stays.
