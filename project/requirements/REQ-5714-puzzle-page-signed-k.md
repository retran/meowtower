# REQ-5714

Every puzzle page MUST be signed «С.» (K., for «Смотрительница», Keeper), except a page that carries «И.» as a running clue under REQ-5716.

The canon has the Diary's author sign «С.», and keeps «И.» for a few forgotten pages that are one of the mystery's clues.
