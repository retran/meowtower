# REQ-1972

A battle MUST be a run of checks: each move the player makes is a maths task, a clean outcome lands the move in full, a partial one lands it weakened, and a failed one or «Не знаю» (I don't know) misses.

A battle is fought by solving, like every other check, so a battle won is a battle solved.
