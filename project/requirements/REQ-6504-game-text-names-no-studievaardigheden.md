# REQ-6504

Text the game writes into the report and the Parent Room MUST NOT name a Studievaardigheden test.

A school document the parent imports shows as the school wrote it, because quoting the school claims nothing for the game. A string file or a Parent Room schema that names the test fails the requirement.
