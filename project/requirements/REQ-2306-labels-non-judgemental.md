# REQ-2306

Every report label MUST be non-judgemental, in the style of «пока не освоено» (not mastered yet), «понимает, нужна скорость» (understands, needs speed) and «прочно» (solid), never «плохо» (bad) or «отстаёт» (falls behind).

The parent judges the wording.
