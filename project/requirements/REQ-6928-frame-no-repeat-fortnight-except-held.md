# REQ-6928

The game MUST NOT show the player a story frame it showed her in the last 14 days while the structure has a frame it hasn't shown, unless every frame it hasn't shown is set in a context that REQ-6926 holds back or that REQ-6956 keeps out of the slot.

A repeat costs the player one familiar text and the log marks it, while releasing the held context costs the subtype's only near observation after mastery. While a structure has only 5 frames, as at stage 0.2, the hold makes some frames repeat within 14 days, and REQ-6982 says which frame the repeat takes.
