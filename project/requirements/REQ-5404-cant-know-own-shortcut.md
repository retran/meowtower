# REQ-5404

On the computer interface, «Нельзя узнать» (can't be known) MUST have a keyboard shortcut of its own, different from the shortcut of «Не знаю» (I don't know) and from every key that enters an answer.

A shared key would record an answer she didn't choose, the same slip the separate placement guards against. I chose not to name the key, which the design step picks.
