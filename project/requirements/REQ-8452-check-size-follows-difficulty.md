# REQ-8452

A check MUST hold 1 task for an ordinary obstacle, 2 for a hard one and 3 for a Guardian or an adventure's final obstacle, by the difficulty the encounter declares for it.

A harder obstacle asks for more solving, so its success means more. The numbers are starting values that I chose for the content file.
