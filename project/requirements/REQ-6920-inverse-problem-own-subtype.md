# REQ-6920

The skill graph MUST hold every inverse problem, such as finding a side from the perimeter, as a subtype or node of its own, never as a format of the direct problem's subtype.

The player's first attempt on an inverse problem then counts as a first meeting with a new subtype, which the addendum calls far transfer.
