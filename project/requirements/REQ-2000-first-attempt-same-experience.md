# REQ-2000

Withdrawn by ADR-3220 under REQ-7980: the game accumulates no experience.

An unassisted first attempt MUST earn the same experience whether the answer is right, wrong or «Не знаю» (I don't know).

A guess then earns no more than an honest answer.
