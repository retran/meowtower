# REQ-5736

Apart from a puzzle's solution page in the Diary, the game MUST NOT offer lessons that teach a new maths topic.

The game measures and consolidates, and the parent teaches new topics in lessons outside it; the short solution and the second attempt after a task stay tied to that task. A solution page teaches circle ideas such as parity and the pigeonhole principle, which the owner wants the branch to train and which no node of the skill graph covers. The parent judges it.
