# REQ-5816

When the parent enters a Cito result for a horizon, the Director MUST work toward the next horizon, and with no later horizon left, give block priority no weight until the parent sets a new one.

The school picks its own test day, so the date the parent set is only an estimate, and the result is what shows the test has passed. Giving block priority no weight after the last horizon is a default chosen while writing this requirement, because the priority exists to meet a test date.
