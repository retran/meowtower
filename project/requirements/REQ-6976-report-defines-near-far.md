# REQ-6976

The report MUST define near transfer as «новый формат или сюжет знакомого подтипа» (a new format or setting of a known subtype) and far transfer as «новый подтип, пререквизиты которого освоены» (a new subtype whose prerequisites she has mastered).

Near and far mean different distances in different studies, so the parent needs the game's own meaning of each word.
