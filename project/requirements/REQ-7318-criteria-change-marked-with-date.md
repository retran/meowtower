# REQ-7318

When a hypothesis's criteria have changed after it was recorded, the report MUST mark it «критерии изменены после записи» (criteria changed after it was written) with the date of each such change.

A change of criteria after seeing data is allowed only when it is dated and visible (Nosek and colleagues, 2018).
